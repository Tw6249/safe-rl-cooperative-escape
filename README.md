## 使用

进入 `03_期刊论文_安全强化学习协同脱困` 后运行 `./build.ps1` 编译中英文论文。`./build.ps1 -Figures` 会重新生成图件；需要本机 Python 科学计算依赖、TeX Live/latexmk 和相应字体。已有 PDF 可直接阅读。

原 `.venv_dgppo` 一并保留，但 Python 虚拟环境并非通用可移植环境：其 pyvenv.cfg 和部分启动器保留创建时的绝对路径。若环境启动失败，使用 `comparison_revision_20261109/requirements_dgppo_locked.txt` 在新的环境目录重建；不覆盖旧环境记录。原 Python 基础解释器位于 D:/miniconda/envs/learning_env。

本次整理不重跑训练、闭环实验、审计或图件生成，不改变实验结论。新实验必须使用新的输出目录，保留失败结果和冻结源码。复制的共享依赖在此作为独立快照使用，不自动与博士论文工作区同步。
