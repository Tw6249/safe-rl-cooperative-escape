- **S（必须满足的条件）**：所有运行的全部执行段精确有理数审计 0 失败。出现失败即如实报告并停止该组的性能解读。

  - 运行前的预测（不是判据）：对称化在严格对称构型上令 ω ≡ 0，等价于退回短视标称，故 SYM 上会停滞，在格点交换上也会变慢。

  - 运行前的预测：训练规模上闭邻域平均已含 91.5% 的队员（§5.1），块奖励近似团队奖励，预计无可测差异。
- **H2a（升级二的机理）**：投影正则降低测试中的平均滤波干预量 mean‖u − Π_U(u^nom)‖。
- **H2b（建议稿声称的收益）**：投影正则降低执行指令跳变（‖u_k − u_{k−1}‖/Δt 的均值与超过 0.8 m/s² 的比例；0.8 m/s² 为第六章底盘 a_max，仅作参考阈值，本仿真为一阶模型）。
- **H2c（任务性能不受损）**：投影正则不劣于无正则（到达数不少，配对时间差中位数 ≤ +0.5 s）。
  - 运行前的预测：可能变慢——命题 5.3 中静止邻居的退让由移动者“顶向约束”的标称分量驱动，把标称拉回安全输出会削弱这一驱动。
- **H12（建议稿推荐的组合）**：升级一 + 升级二 相对基线（两者都关）按 H1、H2a～c 的同一组指标报告。


## 3. 方法

### 3.1 训练（`code/train_ext.py`）

冻结论文训练器 `train_ppo.py` 只读加载（HP、`assemble`、`gather`、`boot_values` 原样复用）；变体 `full`（几何 + 代数输入），μ 门控，训练期 B = 2，无包络，与 `train_full02` 相同。验证集、选模规则（得分 = 成功率 − 0.001 × 成功回合平均用时）不变。两项开关：

- **升级一 `--critic local`**：价值网络与论文 Critic 同一 GNN，去掉图池化，每个机器人一个值 V_i = f(h_i, glob)；拟合块奖励 R_{i,k} = mean_{j∈N_{i,k}^+} r_{j,k}，N^+ 为 2.5 m 闭邻域（与滤波器 L 同一图）；r_j 是团队奖励的逐机器人拆分：r_j = N·(‖e_{j,k}‖ − ‖e_{j,k+1}‖)/D_0 − 10⁻³ − 0.02·φ_j + 1[成功]，满足 mean_j r_j 严格等于论文团队奖励；逐机器人 GAE，PPO 比率用各自优势。
- **升级二 `--proj λ`**：演员损失加 λ·mean_i‖Π_U(u_i^nom(μ_θ)) − sg(u_i)‖²。u^nom 由策略均值经与 `ResidualFlow.compose` 相同的合成得到（直通裁剪：前向用裁剪值，反向不截断梯度），u_i 为该拍滤波器实际输出，Π_U 为速度球投影。与建议稿公式的差别：建议稿写的是 ‖u^nom − sg(u^safe)‖²，但 u^nom 含不截断的 −e_i（置换任务中可达 3～4 m/s），按原式会主要惩罚速度球截断而不是安全滤波干预，故改为 Π_U(u^nom)，与建议稿 5.1 条与代码中“滤波修正量”的定义一致。
- **λ 的标定规则（冒烟运行前写定）**：在初始策略的冒烟运行中测第一个小批次上的 ‖∇L_proj‖/‖∇L_PPO‖（演员参数），在 {0.01, 0.03, 0.1, 0.3, 1, 3} 中取使 λ·比值最接近 1（对数尺度）的值；训练全程逐轮记录该比值。

### 3.2 执行与评测（`code/eval_ext.py`、`code/exp_common.py`）

与论文证据相同的运行器、滤波器与审计：冻结 `pa_bridge.run_pa`，L = `evaluate.budget_oracle(ShieldOracle)`（局部结清，诊断中心 QP 关闭，诊断 QP 本来不驱动机器人），B = 8，60 s，步数上限 3600，冻结精确有理数审计。学习组的标称为论文部署形式：门控残差 × 邻域完成包络 ρ_i（`20261103_终段包络验证` 的 `EnvelopedResidualFlow`，ε_g = 0.05），μ 门控。`ExtFlow` 只额外记录诊断量（干预量、标称大小、原始动作饱和比例、移动者侧向分量），不改变任何计算（§5.3 逐位核对）。

### 3.3 思路 6 的实现

镜像（反射）下各特征的奇偶性由 `code/test_o2.py` 数值核对（§5.2）：节点几何特征第 5、8 列（v·Jê、δ·Jê）与边几何特征第 3、5、8、10 列（r·Jê_i、r·Jê_j、(Jê_i)·ê_j、(v_j − v_i)·Jr）为奇，其余全部为偶（含全部代数特征）；输出中 ω（Je_i 的系数）为奇，ρ、ψ 为偶。对称化策略 `O2Policy`：ω_sym = ½[ω(x) − ω(Px)]，ρ_sym = ½[ρ(x) + ρ(Px)]，ψ_sym = ½[ψ(x) + ψ(Px)]，P 为奇特征取反——即建议稿的奇偶差分。镜像场景：位置与目标取 y → −y。

## 9. 总结（2026-11-07 写定）

### 9.1 建议稿各条在本轮的结论

1. **升级一（闭邻域局部 Critic）没有用，且略有害。** 训练规模上闭邻域平均已含 91.5% 的队员，块奖励与团队奖励几乎相同；它的实际效果是学得更慢（首次 1.000 晚 16～24 轮），测试中到达更少、更慢（不超过种子噪声，结论只到“没有益处”）。建议稿用 N = 20 外圈静止机器人论证的信用分配问题，在 N ≤ 10 的训练分布里不存在。
2. **升级二（护盾投影正则）机理成立，但没有改善任务表现。** 它确实把滤波干预降了 40%～70%，并让早期学习快得多（7 万步验证即 0.97～1.00），但训练后期不稳定（4 次中 3 次验证下滑），按论文的选模规则选出的是早期检查点；测试中不增加到达，共同到达场景慢 2.0 s，指令跳变的尾部（p99）反而变大，失败形态由冻结变为活锁。建议稿“平滑标称 → 二阶底盘推力饱和减轻”的推论没有得到支持。
3. **推荐组合（升级一 + 升级二）比基线差**（到达 2:7，时间 +2.6 s）。
4. **思路 6（O(2) 对称化）显著有害**（30/48 对 48/48，p = 7.6e-6），在严格对称构型上退化为短视死锁；但它指出的手性问题真实存在（N = 25 镜像场景明显变差），处理方向应是让策略感知哪一侧更空，而不是去掉手性。
5. **事实前提**：动作饱和不存在（全部检查点 0.000）；“训练期门控抑制自由空间探索噪声”与门控 98%～99% 常开的记录矛盾；表 5.3 B 的 0.8887 m/s 是单场景破死锁阶段的值。
6. 未检验的条目（1.1、1.2、2、4、5.2、升级三、升级四）的理由见 §1；其中非等变基线与无护盾惩罚基线是答辩防线，不是改进，本轮未做。

### 9.2 本轮的附带发现（对第五章正文更重要）

2. **训练随机性很大，正文中的跨规模与模块消融结论需要改写措辞。** 同一配置两个种子的 E2n 到达数可差 4/16 对 9/16、8/16 对 14/16；种子 2 在四个配置上全部优于种子 1（17:1）。按论文配方（同 HP、同验证选模、新种子、一半预算）重训的两个基线是 44/48 与 46/48，均不如论文检查点（0:6，p = 0.031，慢 1.55 s；预算减半是混杂因素）。由此：表 5.2 的“32/32 零样本迁移到 N = 12～25”应表述为“一次训练得到的策略”的结果；表 5.3 A 中“纯几何 22/32、修正量门控 15/32”是单种子检查点之间的比较，其差距落在本轮观察到的同配置种子间差异范围之内，不能归因于代数特征或门控（与 20261103_包络公平检验 §5 H-A 的保留意见一致）。
3. **镜像敏感性**：N = 25 的四个交换镜像后，论文检查点 1 个未到达、2 个显著变慢；以前的 E2 结果都在同一朝向上得到。
4. **正文与代码不一致（未改动正文，仅记录）**：第 5.4.4 节写训练为 N = 8、格距 1.001～1.08 m、f ∈ [0.50, 0.88]、施加微幅位置扰动；代码 `train_scene` 为 N ∈ {6,…,10}、格距 1.001～1.12 m、f ∈ [0.55, 0.90]、无位置扰动。式 (5.32) 的奖励（按 NΔt 归一、指示函数型停滞惩罚、ε_u = 0.005）与代码（按 D₀ 归一、tanh·exp·log(1+‖μ‖²) 平滑停滞项、ε_u = 0.05）不同。
