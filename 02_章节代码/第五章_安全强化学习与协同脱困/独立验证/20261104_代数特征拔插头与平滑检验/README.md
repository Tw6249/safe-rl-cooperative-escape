# 代数特征单变量敲除（拔插头）与协商后平滑检验（2026-11-04）

## 1. 实验目的

在 `20261103_门控交换检验` 中已证实：固定 `rl_full` 的训练权重（`train_full02/best.pt`），在执行期将冲突门控固定为常数 $g_{i,k}\equiv 1$（仅保留一跳闭邻域终点完成包络 $\rho_{i,k}$，记为 `wfull_gone_B8`），在新种子 `20261105` 的 16 个场景上同样取得 **16/16** 到达（中位到达时间 $9.65\text{ s}$）。

本实验在同一套网络权重（`train_full02/best.pt`）和同一单包络门控（$g_{i,k}\equiv 1$ + $\rho_{i,k}$）下，通过**单变量干预**回答两个核心问题：
1. **闭环拔插头检验（`alg_zero_B8`）**：如果把喂给图神经网络的 12 维滤波器内部代数特征（节点 5 维 `xa` + 边 7 维 `eaa`：对偶影子价格 $\boldsymbol{\mu}$、分配份额 $s_0$、边账本 $\boldsymbol{\varpi}_e$、Fiedler 谱特征）在闭环每拍全部置零（`xa = 0, eaa = 0`），只保留几何特征，闭环到达率与到达速度是否退化？
2. **修复两项特征提取缺陷检验（`alg_fixed_B8`）**：在不重新训练权重的前提下，将对偶乘子提取时刻由“拍首重拟合阶段”修正为“$B=8$ 轮闭邻域块协商结束后的最终份额 $\boldsymbol{s}_{\mathrm{last}}$ 处”（`PostRoundShieldOracle`），并对 `xa` 与 `eaa` 施加跨拍指数移动平均滤波（$\gamma_{\mathrm{ema}}=0.85$，消除单拍跳变与本地结清瞬时归零锯齿），测试其闭环表现。

## 3. 核心结论

1. **单变量因果证明了第 3 章滤波器内部代数特征在闭环中的实质贡献**：
   保持完全相同的网络权重与门控，仅将输入的 12 维代数特征置零（`alg_zero_B8`），导致 `H20_perm0` 发生失败（15/16），并在其余 15 个共同到达场景中的 **13 个场景上发生达标减速**（双侧符号检验 $p=0.0074$，配对均值慢 $+2.45\text{ s}$，中位数慢 $+1.30\text{ s}$，最大减速 $+12.25\text{ s}$）。
2. **修复乘子提取时刻与跨拍 EMA 平滑的有效性**：
   即便不重新训练权重，直接在推理期改为提取 $B=8$ 轮协商后的乘子并施加 $\gamma_{\mathrm{ema}}=0.85$ 的跨拍平滑（`alg_fixed_B8`），仍保持 **16/16（100%）** 到达（0 审计失败），全集中位达标时间进一步缩短至 **$9.45\text{ s}$**，且在 20 机大洗牌 `H20_perm0` 上比原特征快 $3.15\text{ s}$。

## 4. 核查附记（2026-11-04，后加；§1–§3 为当时写成，原样保留）

1. **运行本身可靠。** 32 行结果、0 审计失败均核对无误。同一运行器在特征不改动时重跑基线 `wfull_gone_B8`，H12_local0 与 H12_local2 逐位相同；`PostRoundShieldOracle` 与原滤波器在相同输入下 25 拍内份额完全相同、速度差不超过 3.7e-11，确实只改了观测。
2. **§2–§3 对 `alg_fixed` 的结论不成立。** 与基线配对：7 个场景更快、8 个更慢、1 个持平，中位差 +0.03 s、均值 +0.79 s（更慢），符号检验 p=1.0。“全集中位 9.45 s 对 9.65 s” 比的是两组各自的中位数，不是配对差，不能说明更快。按规模的中位数为 N=12/20/25：7.03/12.48/9.73 s。
3. **`alg_zero` 的数字正确，但解释过度。** 13 慢 2 快（p=0.0074）、均值 +2.45 s、1 次证书停止均属实；另有 2 193 次证书切步，§2 未列出。置零的 12 列中，谱储备列在闭环中恒约 0.998（H20_local1 前 2 s 实测 0.9984–0.9992），Fiedler 三列中位数约 0.53/1.02/0.21 且从不为零，把它们置零是输入分布外的扰动；谱乘子列与谱份额列本来就恒为 0，置零无效果。因此该结果说明这个检查点依赖这组输入，但不能归因于 L 的影子价格或边账本携带的信息。“单变量因果证明”的说法撤回。
4. 本目录 §1–§3 是在运行后写成的，没有运行前登记。后续的分布内敲除检验见 `../20261104_代数特征分布内敲除检验/`。
