# 终段邻域衰减包络验证：消除大规模悬停近失并确立完整方法优势（2026-11-03）

## 1. 验证目的

在 `20261102_安全强化学习` 的跨规模零样本测试（E2，$N=12, 20, 25$ 共 16 个场景）中，采用代数特征与 KKT 影子价格门控的完整方法 `rl_full` 在全部 16 个场景上都将最大目标误差推进到了 $0.4\sim 1.1\text{ cm}$（零死锁、零冻结），但因密集格点（间距 $1.001\text{ m}$，净空 $1\text{ mm}$）在终点处避碰约束仍近激活，$\|\boldsymbol{\mu}_i\|_2>0$ 使影子价格门控保持常开，邻域排斥项 $+A_\psi U \mathrm{mean}_j \psi_{ij}(\boldsymbol{p}_i-\boldsymbol{p}_j)/d_{ij}$ 不随目标误差归零，导致在 $N=20$ 的 4 个场景上出现 $1.9\sim 5.1\text{ cm}$ 的终点抖动（悬停近失，未满足“$1\text{ cm}$ 内连续保持 $1\text{ s}$”的到达判据）。

本目录在不重新训练、不修改任何已保存模型权重（直接加载 `20261102_安全强化学习/results/train_full02/best.pt`）的前提下，检验在 `ResidualFlow.compose` 中加入**一跳闭邻域完成包络**：
$$\rho_i = \tanh\!\Big(\frac{\max_{j\in\mathcal{N}_i^+}\|\boldsymbol{e}_j\|_2}{\varepsilon_g}\Big),\qquad \varepsilon_g = 0.05\text{ m},\qquad g_i^{\mathrm{eff}} = \tanh(4 m_i)\cdot \rho_i,$$
能否在不损失任何协调解锁能力的前提下，从数学构造上消除终点悬停，实现小规模（E1）与跨规模（E2）100% 到达。
